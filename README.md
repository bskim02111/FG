# FocusGuard AI 시뮬레이터 (웹 버전)

TEAM DORI · FocusGuard — 플라즈마 식각 포커스링 마모 · 잔여수명 시뮬레이터 `focusguard_ai.py`를 브라우저용으로 옮긴 페이지입니다.

- 주소: https://bskim02111.github.io/FG/
- 원주 팹 8챔버 링 수명 수집 → 자동 재학습 → 정확도 · 연간 절감액 (파이썬 앱과 같은 시드 · 같은 숫자)
- **LoRa 송신**: 컴퓨터용 Chrome · Edge에서 송신 아두이노(`lora_tx.ino`)를 USB로 꽂고 상단 LoRa 표시의 **USB 연결**을 눌러 포트를 한 번 고르면,
  파이썬 앱과 똑같이 시뮬레이션 상태를 보내고 학습 샘플 1,000개를 넘는 순간 수신측으로 LoRa 알림이 나갑니다.
  한 번 고른 포트는 Chrome이 기억해서 다음부터는 자동으로 연결됩니다.
  (아두이노 IDE 시리얼 모니터나 파이썬 시뮬레이터가 같은 포트를 쓰고 있으면 먼저 닫아 주세요.)
